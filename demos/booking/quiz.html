About this demo

A quiz funnel swaps a long form for a few easy taps, so more visitors finish and each one sees a plan and a price made for them. Every answer arrives with the booking, so the owner knows the pool before calling back. William McIlleron built this to show what a booking system on your own site can do. See the booking service
